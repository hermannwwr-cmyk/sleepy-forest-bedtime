# Sleepy Forest Bedtime

A kids' bedtime alarm in a single web page. Two cartoon friends, a round grey forest friend and a little orange dragon, act out each step of the evening with a music-box chime and a friendly voice.

| Time | Step | Scene |
|---|---|---|
| 9:25 pm | Biscuit and milk | The forest friend munches a biscuit next to a cup of milk |
| 9:35 pm | Bedtime reading | The little dragon reads by lamplight |
| 9:55 pm | Brush your teeth | The forest friend brushes with foamy bubbles |
| 10:10 pm | Lights dim | Both climb into bed as the moon rises |
| 10:15 pm | Lights off | Both fall fast asleep |

## Features

- A pop-up card with an animated scene, chime and spoken message at each time
- An **I did it!** button that earns a star for each step
- The page dims at lights dim and goes dark at lights off
- A flashing **NO SCHOOL!** badge when tomorrow is a weekend or a Singapore public holiday
- Editable times, saved on the device
- A **Watch** button to preview any scene

## Use it

Open `index.html` in a browser on a tablet or phone near the bed. Tap **Turn on tonight's alarms** once each evening so it can play sound, then leave the page open. Alarms only ring while the page is open.

## Public holidays

Singapore public holidays for 2026 and 2027 are built into `index.html` (the `HOLIDAYS` list). They come from the Ministry of Manpower's dataset on [data.gov.sg](https://data.gov.sg) (collection 691). Add later years to that list when they're published. Weekends are worked out automatically.

## Characters

Both characters are original drawings made for this page.
